# yandex_archive_scraper — версия 1.1 (реконструкция)

> **Это реконструкция.** Оригинальный файл версии 1.1 не сохранился. Скрипт восстановлен обратно из
> расширения [yandex-archive-extension](https://github.com/MasterGoodwin2/yandex-archive-extension) 1.1.0:
> логика разбора перенесена из JavaScript в Python один в один и сверена с оригиналом на тестовых данных
> (результаты разбора совпадают). Оболочка (вход в Яндекс, запуск браузера, окна выбора файлов, запись Excel)
> в расширении другая, поэтому взята из версии 1.3. Реальный запуск на страницах Яндекс Архива не проверялся.

Добавлено: два типа обработки (исповедные ведомости / ревизские сказки), номер двора и два возраста для ревизских сказок, дата документа со страницы, автоопределение окна распознанного текста (настройки TEXT_SELECTOR / DATE_SELECTOR), остановка после 3 страниц без текста.

## Установка
```
python3 -m pip install -r requirements.txt
```
Нужен Google Chrome (скрипт запускает его сам или подключается к Chrome с `--remote-debugging-port=9222`).

## Запуск
```
python3 yandex_archive_scraper.py
```
Скрипт спросит HTML со ссылками и место сохранения Excel, затем тип обработки; вход в Яндекс вы выполняете сами в окне браузера.
Остановка — Ctrl+C: собранное сохраняется.

Актуальная версия скрипта — в ветке `main`.
