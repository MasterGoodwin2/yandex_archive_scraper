# yandex_archive_scraper — версия 1.0 (реконструкция)

> **Это реконструкция.** Оригинальный файл версии 1.0 не сохранился. Скрипт восстановлен обратно из
> расширения [yandex-archive-extension](https://github.com/MasterGoodwin2/yandex-archive-extension) 1.0.0:
> логика разбора перенесена из JavaScript в Python один в один и сверена с оригиналом на тестовых данных
> (результаты разбора совпадают). Оболочка (вход в Яндекс, запуск браузера, окна выбора файлов, запись Excel)
> в расширении другая, поэтому взята из версии 1.3. Реальный запуск на страницах Яндекс Архива не проверялся.

Базовая версия: диапазон страниц берётся ровно из ссылки; текст — из блока распознанного текста; строки под заголовком населённого пункта округи сохраняются как есть, числа 1–110 идут в колонку «Числа-возрасты (черновик)».

## Установка
```
python3 -m pip install -r requirements.txt
```
Нужен Google Chrome (скрипт запускает его сам или подключается к Chrome с `--remote-debugging-port=9222`).

## Запуск
```
python3 yandex_archive_scraper.py
```
Скрипт спросит HTML со ссылками и место сохранения Excel; вход в Яндекс вы выполняете сами в окне браузера.
Остановка — Ctrl+C: собранное сохраняется.

Актуальная версия скрипта — в ветке `main`.
